# MARSMISSION v1.0.0 — Release Notes

**Status:** Packaging prepared. Public distribution only after smoke tests on clean machines.

## Highlights

- Full three-mission campaign (Communications, Power, Rover Rescue)
- Optional Research Terminal with curated NASA educational datasets
- Procurement with Research Points; world supply caches for softlock-free progression
- Packaged Windows ONEDIR build via PyInstaller
- macOS build scripts for native `.app` packaging (build on Mac)

## Saves

Campaign schema remains independent of app version. Saves live under the OS application-data folder.

## Build artifacts (expected)

- `releases/windows/MARSMISSION_Windows.zip`
- `releases/macos/MARSMISSION_macOS.zip` (when built on macOS)
- `releases/checksums/*.sha256`

## Not included in this app version claim

- Automatic itch.io upload
- Apple notarization
- Universal2 macOS binary (unless separately built and tested)
