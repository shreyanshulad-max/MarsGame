Rover sprite pack (optional)
============================
Place transparent PNGs here to replace the procedural rover:

  rover_top.png      Top-down exploration rover facing RIGHT (+X)
  rover_wheels.png   Optional wheel overlay sheet
  rover_shadow.png   Optional soft shadow
  rover_lights.png   Optional headlight cone

Fallback path also checked: assets/vehicles/rover.png

The game caches rotations and never loads these every frame.
