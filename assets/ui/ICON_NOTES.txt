Application icon notes
======================
marsmission_icon.png  — placeholder Mars/rover mark (256×256)

For Windows PyInstaller EXE branding, convert to .ico:
  - Place marsmission_icon.ico in this folder
  - packaging/MarsMission.spec will pick it up automatically
